# Skill: Forms Handling

## Purpose

Ensure consistent and scalable form implementation.

## Rules

- Use Reactive Forms for all non-trivial forms

- Form logic stays inside components

- Services must not manage form state

- Validation must be explicit and readable

- Avoid complex logic in templates

## Anti-Patterns

- Template-driven forms for complex cases
- Moving form logic to services
- Overcomplicated template bindings
